# How to start

```sh
npm install
npm run dev
```

## Tools

- node/npm
- [handlebars](https://handlebarsjs.com) for templating
- [express](https://expressjs.com/en/5x/starter/installing/) backend framework
- [zod](https://zod.dev/) for data validation
- [mariadb](https://mariadb.com/docs/connectors/mariadb-connector-nodejs)
- [i18n](https://github.com/mashpie/i18n-node) for internationalization
